# Lumen UI icons

Symbolic icons used by the Lumen frontend for its own user interface (taskbar, tray,
flyouts). They are shipped with the frontend, so the UI looks the same regardless of the
icon theme selected by the user. Application icons still come from the user's icon theme.

Source: Breeze icon theme by KDE (https://invent.kde.org/frameworks/breeze-icons),
licensed under LGPL-3.0-or-later. The files are copied unchanged from
`/usr/share/icons/breeze/` (sizes 24 / 22 / 16 px, weather icon 48 px).
