# Maia UI icons

Symbolic icons used by the Maia frontend for its own user interface (desktop context menu).
They are shipped with the frontend, so the UI looks the same regardless of the icon theme
selected by the user.

Source: Breeze icon theme by KDE (https://invent.kde.org/frameworks/breeze-icons),
licensed under LGPL-3.0-or-later. The files are copied unchanged from
`/usr/share/icons/breeze/` (sizes 24 / 16 px).
